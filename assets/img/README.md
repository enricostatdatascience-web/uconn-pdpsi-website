# Images

Drop chapter photos here and reference them from the HTML as `assets/img/filename.jpg`.

Tips:
- Resize to about 1600px on the long edge before committing — GitHub Pages serves the file
  as-is, and a 6MB phone photo will make the page slow.
- Use `.jpg` for photographs, `.png` for logos with transparency, `.svg` for line art.
- Add `loading="lazy"` to any image below the fold.
